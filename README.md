# 📱 LearningApp

iOS application designed to help users build consistent daily learning habits and protect their progress with goal tracking and streak management.

---

## ✨ Features
- 📊 **Daily Activity Tracking:** Easily track learned and frozen days with intuitive status indicators.
- 🎨 **Glassmorphism Dark Mode UI:** A clean, modern, and immersive dark aesthetic built with SwiftUI.
- ⚙️ **Strict MVVM Architecture:** Clean separation of concerns ensuring maintainability and smooth state management.
- ⏱️ **Time & Status Management:** Dynamic timer and logic to monitor daily activity intervals and prevent broken habits.

---

## 🛠️ Tech Stack
The app is built using modern native iOS development frameworks:
- **Language:** Swift 🍏
- **UI Framework:** SwiftUI
- **Architecture:** MVVM (Model-View-ViewModel)
- **State Management:** `@Observable`
- **Local Storage:** UserDefaults
